Lab 4.1: Troubleshooting Windows IP Configuration

Scenario: Workstation PC-SALES-02 cannot connect to the local gateway or external networks after a recent static IP migration.

Task Objectives

  1. Use ipconfig to inspect the current network adapter parameters.
  2. Compare the workstation configuration against the baseline target network specification below to locate the incorrect address parameter.
  3. Use the netsh command to assign the correct static IP configuration:
    netsh interface ip set address name="Ethernet" static [IP] [Subnet] [Gateway]
  4. Verify connectivity using ping 192.168.1.1.
Target Local Network Specification:
  • Subnet Range: 192.168.1.0/24 (Subnet Mask: 255.255.255.0)
  • Default Gateway: 192.168.1.1
  • Assigned IP for PC-SALES-02: 192.168.1.45
